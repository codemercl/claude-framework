# Token Audit — Замер и оптимизация потребления токенов

Твоя задача — замерить сколько токенов потребляет Claude Code на старте сессии (с проектом и без), проанализировать источники потребления и предложить конкретные оптимизации. Не менять настройки без явного согласия пользователя.

## Instructions

### 1. Подготовить прокси и замерить базовый контекст

Проверить наличие прокси-скрипта: `ls ~/.local/bin/claude-cache-proxy.js`. Если нет — создать (см. секцию Proxy Script ниже).

Сказать пользователю:

```
Шаг 1: замеряем базовый контекст без проекта.

Терминал 1 — запусти прокси:
  node ~/.local/bin/claude-cache-proxy.js

Терминал 2 — запусти Claude Code:
  cd ~ && ANTHROPIC_BASE_URL=http://localhost:9999 claude

Отправь 2 коротких сообщения (например "привет" и "как дела").
Скинь мне вывод из терминала с прокси — строки "Запрос #1" и "Запрос #2".
```

Дождаться результата. Зафиксировать: cache read на запросе #2 = базовый контекст без проекта.

### 2. Замерить контекст с проектом

Сказать пользователю:

```
Шаг 2: замеряем контекст с проектом.

Закрой Claude Code в терминале 2 (/exit).
Запусти заново из папки проекта:
  cd ~/Desktop/alldigitals/react && ANTHROPIC_BASE_URL=http://localhost:9999 claude

Отправь 2 коротких сообщения.
Скинь вывод из прокси.
```

Дождаться результата. Зафиксировать: cache read на запросе #2 = контекст с проектом.
Вычислить: разница = стоимость проекта в токенах.

### 3. Проанализировать и предложить оптимизации

Выполнить все проверки через Bash/Read:

```bash
# Размеры файлов контекста
wc -c ~/.claude/CLAUDE.md
wc -c CLAUDE.md 2>/dev/null  # проектный
wc -c .claude/rules/*.md 2>/dev/null

# Rules без globs (грузятся всегда)
for f in .claude/rules/*.md; do
  head -5 "$f" | grep -q "globs:" || echo "БЕЗ GLOBS: $f"
done

# Хуки (инъекции в контекст)
cat ~/.claude/settings.json | python3 -c "
import json,sys
d = json.load(sys.stdin)
hooks = d.get('hooks', {})
for event, items in hooks.items():
    for item in items:
        for h in item.get('hooks', []):
            print(f'{event}: {h.get(\"command\",\"\")[:80]}')
"

# MCP серверы
cat ~/.claude.json | python3 -c "
import json,sys
d = json.load(sys.stdin)
for name, conf in d.get('mcpServers', {}).items():
    disabled = conf.get('disabled', False)
    print(f'{\"ВЫКЛ\" if disabled else \"ВКЛ\"}: {name}')
"

# Memory файлы
wc -c ~/.claude/projects/*/memory/*.md 2>/dev/null | tail -1
```

Составить отчёт и предложить оптимизации с оценкой экономии.

## Non-Negotiable Acceptance Criteria

1. **Два замера обязательны**: Всегда замерять и без проекта, и с проектом. Без двух точек невозможно понять что именно жрёт токены.
2. **Запрос #2 для замера**: Использовать cache read из второго запроса, не первого.
3. **Не менять настройки**: Только анализировать и предлагать. Пользователь сам решает что отключать.

## Proxy Script

Если `~/.local/bin/claude-cache-proxy.js` не существует, создать со следующей логикой:
- HTTP сервер на порту 9999
- Проксирует запросы к api.anthropic.com:443
- Парсит SSE-ответы: message_start (input + cache tokens), message_delta (output tokens)
- Показывает на каждый POST /v1/messages: cache read, cache write, новые токены, ответ, итого, нарастающий cache hit %
- Цвета: зелёный ≥80%, жёлтый ≥40%, красный <40%
- При Ctrl+C показывает итоги сессии
